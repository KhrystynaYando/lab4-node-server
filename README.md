Для запуску сервера використовується команда : node main.js -i bank_managers.json -h 127.0.0.1 -p 3000 -o output.json
Доступні HTTP запити:
1. Щоб отримати всі банки: curl -i 'http://127.0.0.1:3000/'
2. Щоб отримати банки з МФО: curl -i 'http://127.0.0.1:3000/?mfo=true'
3. Щоб отримати банки зі станом "1": curl -i 'http://127.0.0.1:3000/?normal=true'
4. Щоб використати обидва параметри: curl -i 'http://127.0.0.1:3000/?mfo=true&normal=true'
5. Щоб перевірити обробку неправильного шляху: curl -i 'http://127.0.0.1:3000/hello'
